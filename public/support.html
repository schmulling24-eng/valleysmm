❓ Common Issues

My M-Pesa payment didn't credit my wallet

Wait 5 minutes. If still not credited, open a ticket or WhatsApp us with your M-Pesa transaction code (starts with letters, e.g. QHX1234ABC).

My order is stuck on "Pending" for a long time

Most orders start within 0–30 minutes. If your order has been Pending for more than 2 hours, open a ticket with your Order ID and we'll check it immediately.

I received fewer followers/likes than ordered

If your order status is "Partial", you'll receive an automatic refund for the undelivered portion. If it says "Completed" but count is wrong, open a ticket within 24 hours.

How do I cancel an order?

Orders can only be cancelled before they start processing. Open a ticket immediately with your Order ID and we'll try to cancel it. Cancellations are not guaranteed once started.

How do I become a reseller?

Visit the API Access page to get your API key and view documentation. For white-label panel setup, contact us on WhatsApp.
